# DevUniverse  — 8 Sheets in 1 App
### Built entirely on Android phone in Pretoria, South Africa 🇿🇦

**Version:** v0.5.1 ENV SECURED | **Pandas 3.0.3 ✅ | Secrets from .env 🔒**

DevUniverse is an all-in-one development environment that runs 100% on Android.

### 📱 8 Sheets in 1:
1. **Choose Language** — Python / JavaScript
2. **Code Editor** — Full editor with syntax
3. **Run** — Execute instantly
4. **Output** — Real-time logs
5. **Files** — Workspace manager
6. **Upload** — PDF, images, datasets
7. **Make ZIP** — Export project
8. **GitHub Ready** — ENV secured, no secrets

### 🔒 Security:
- v0.5.0 → hardcoded secrets (INSECURE)
- **v0.5.1 → secrets from `.env` + `.env.example` + `.gitignore` (SECURED)**
- `.env` never uploaded — only `.env.example`
